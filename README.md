# The Odin Project: Landing Page

This project is a responsive landing page built as part of **The Odin Project** curriculum. It replicates a modern web design using core **HTML5** and **CSS3** layout techniques, specifically utilizing Flexbox.

## Features
* **Header & Hero Section**: Includes a navigation bar with a logo and links, paired with a compelling headline, subtext, call-to-action button, and image placeholder.
* **Information Section**: Features a grid of custom card components with illustrations or image placeholders and accompanying subtext.
* **Quote Section**: A dedicated testimonial section with distinct typography and author alignment.
* **Call to Action (CTA) Section**: A highlighted container encouraging user sign-ups with a contrasting button.
* **Footer**: Clean copyright footer matching the header aesthetic.

## Built With
* HTML5
* CSS3 (Flexbox, Media Query ready)
